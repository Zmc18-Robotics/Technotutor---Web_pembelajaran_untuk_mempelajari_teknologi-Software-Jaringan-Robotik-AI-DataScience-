Folder gambar setiap materi dibuat otomatis saat data materi dimuat:
materials/{bidang}/{id-materi}/{nomor-slide}.jpg

Contoh:
materials/software/1/1.jpg
materials/software/1/2.png

Gunakan editor admin untuk mengunggah, mengganti, menyeret, atau menghapus gambar slide. Jika gambar slide tidak ada, aplikasi menggunakan foto dari folder ../hero-gallery/.
